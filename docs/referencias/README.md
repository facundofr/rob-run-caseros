# Referencias de mercado

Documentos de análisis de otros juegos del género, usados solo como inspiración de diseño.
**No se publican en el repositorio** (están en `.gitignore`): cada miembro del equipo los guarda en esta carpeta en su copia local.

Archivos esperados:
- `rob-run-gdd.md`: análisis de ROB RUN (mecánicas, roles, economía).
- `rob-run-prompt.md`: resumen de roles policía / ladrón / ciudadano de ROB RUN.

Las reglas de Barrio NO salen de acá directamente: están en [../GAME_DESIGN_DOCUMENT.md](../GAME_DESIGN_DOCUMENT.md),
con nombres, valores y escala propios. Estos documentos tienen contradicciones internas (nombre de la
ciudad, NPCs), así que no se toman como datos exactos.
